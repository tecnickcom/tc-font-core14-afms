# Core 14 AFM Files

This project contains a mirror of the Adobe Postscript(R) Core 14 AFM Files originally available from:
https://www.adobe.com/devnet/font/pdfs/Core14_AFMs.zip

These AFM metrics are commonly used by PDF engines to calculate glyph widths, kerning pairs, and text layout without embedding full font programs. Keeping a clean mirror in version control makes builds reproducible and avoids depending on external download endpoints during CI or packaging.
